      Decoding algorithm: how does
      it work?
INPUT: String to be decoded & alphabet with probability distribution
1.    Initialize the range [0,1)
2.    For each symbol of the string:
     1.   Divide the current interval into n subintervals (n= size of the alphabet). Each
          subinterval will have a size proportional to the probability associated with
          each element in the initial alphabet.
     2.   Select as the current interval the symbol corresponding to the subinterval in
          which the value of the input being analyzed falls.

It is a lossless algorithm (without loss of information).
